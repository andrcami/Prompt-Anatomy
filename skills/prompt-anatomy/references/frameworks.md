# Prompt Frameworks

Read this when the user asks for a named framework, or when a task clearly fits one. Frameworks are memory aids, and every one of them is a subset of the anatomy in SKILL.md. Use them as checklists, not cages. The anatomy questions still decide what goes in the prompt, and the frameworks are just familiar ways to lay it out. None of them is tied to one platform. They work on ChatGPT, Claude, Grok, Gemini and others.

## The "GROK Prompt Framework" set (Sarah Morino, Medium, Oct 2025)

These are acronym templates popularised for Grok and other assistants. The article lists 12. The 9 below are the ones in the downloaded copy.

| Framework | Components | Best for | Example |
|-----------|-----------|----------|---------|
| **A.P.E.** | Action, Purpose, Expectation | Writing tasks, blog posts, reports | "Write a blog post about climate change's impact on agriculture. Focus on economic consequences. Include data and expert opinions." |
| **T.A.G.** | Task, Action, Goal | Planning, content calendars, strategy | "Create a 3-month content calendar. Include blog topics and posting schedule. Aim to increase brand awareness." |
| **E.R.A.** | Expectation, Role, Action | Professional analysis, reports | "Provide market analysis. Act as a financial analyst. Include trends, forecasts, and competitor positioning." |
| **R.A.C.E.** | Role, Action, Context, Expectation | Travel, planning, lifestyle | "Act as a travel planner. Create a 7-day itinerary for Japan. Focus on cultural experiences and local cuisine." |
| **R.I.S.E.** | Request, Intent, Style, Expectation | Summarization, formatting | "Summarize this article. Purpose is to extract key points. Use bullet format. Keep it under 200 words." |
| **C.A.R.E.** | Context, Action, Role, Expectation | Coaching, feedback, review | "You are a career coach. Review this resume. Suggest improvements for clarity and impact." |
| **C.O.A.S.T.** | Context, Objective, Action, Style, Task | Product design, pitches | "You are a product designer. Create a pitch for a new app. Use persuasive tone. Focus on solving a common problem." |
| **T.R.A.C.E.** | Task, Role, Action, Context, Expectation | UX research, surveys | "You are a UX researcher. Conduct a user survey. Include questions on usability and satisfaction. Summarize findings in a report." |
| **R.O.S.E.S.** | Role, Objective, Style, Expectation, Situation | Campaigns, social media | "You are a social media manager. Create a campaign for Earth Day. Use engaging tone. Aim to raise awareness and drive participation." |

The article's own guidance: use A.P.E. or R.I.S.E. for writing, T.A.G. for planning and E.R.A. for analysis. Frameworks can be combined for complex tasks, for example R.A.C.E. + C.O.A.S.T. for a product pitch.

## Other widely used frameworks

| Framework | Components | Best for |
|-----------|-----------|----------|
| **R.T.F.** | Role, Task, Format | Quick one-off prompts |
| **CO-STAR** | Context, Objective, Style, Tone, Audience, Response format | Content and communications where tone and audience matter |
| **RISEN** | Role, Instructions, Steps, End goal, Narrowing (constraints) | Multi-step processes and procedures |
| **CRISPE** | Capacity/role, Insight (background), Statement (task), Personality, Experiment (ask for variants) | Creative work where you want several options |
| **B.A.B.** | Before, After, Bridge | Persuasive copy, sales and change narratives |

## Mapping frameworks to the anatomy

| Anatomy element | Appears in frameworks as |
|-----------------|--------------------------|
| Goal | Purpose, Goal, Objective, Intent, End goal |
| Context | Context, Situation, Insight, Before |
| Specifics | (usually missing from frameworks, so add them yourself) |
| Role / audience | Role, Capacity, Audience |
| Constraints | Narrowing, Style, Tone |
| Output format | Expectation, Format, Response |
| Examples | (missing from most, so add them for reusable prompts) |
| Success criteria | Expectation, End goal |

Most frameworks leave out **specifics** (budget, location, dates, data) and **examples**, and those are exactly what make prompts concrete. When you use a framework, still ask the targeted questions from SKILL.md, then slot the answers into the framework's headings.

## Choosing quickly

- Want something fast and short? Use **R.T.F.** or **A.P.E.**
- Tone and audience are critical? Use **CO-STAR** or **R.O.S.E.S.**
- A step-by-step process? Use **RISEN**.
- Feedback or review of the user's material? Use **C.A.R.E.**
- Planning? Use **T.A.G.** or **R.A.C.E.**
- Persuasion? Use **B.A.B.**
- Not sure? Skip the framework and use the anatomy skeleton in `anatomy.md`.
