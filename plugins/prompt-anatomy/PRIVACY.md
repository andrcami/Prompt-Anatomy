# Privacy policy: Prompt Anatomy

*Last updated: 18 November 2026*

Prompt Anatomy is a skill: a set of written instructions that tells an AI assistant (such as Claude) how to ask clarifying questions, build a better prompt and recommend a model. It contains no code, servers, connectors or tracking.

## What data it handles
- **Only what you type in the conversation.** The assistant reads your request and your answers to its questions, inside your existing chat, to build the prompt.
- **No personal data is collected or stored by the plugin.** It doesn't ask for names, emails, addresses or account details, and it saves nothing.

## Where data goes
- **Nowhere outside your AI assistant.** The plugin has no connectors or MCP servers, and sends no data to the author or to any third party.
- If you run the refined prompt with your assistant's **built-in web search** turned on, the search is done by the assistant itself (for example Claude's web search), under that provider's own privacy policy, not by this plugin.

## Retention
- **None.** The plugin retains nothing. Your conversations are kept, or not, according to your AI provider's settings and policy (for Claude, see [Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy)).

## Children
Prompt Anatomy is a general-purpose productivity tool, and it isn't intended for users under 18.
